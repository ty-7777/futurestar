## 1. 引言

### 1.1 编写目的

本文档描述智星足球青训综合管理系统的功能需求、非功能需求、运行环境要求等，作为项目开发、测试和验收的依据，明确各方对系统功能和性能的期望。

### 1.2 项目背景

近年来，随着全民健身和校园足球的普及，青少年足球培训行业快速发展。然而传统青训机构普遍存在管理效率低、训练数据零散、个性化训练指导不足等问题。本项目旨在利用互联网和人工智能技术，打造一个面向足球青训机构的综合性管理平台，为青少年球员提供一站式体能管理、训练预约与 AI 智能训练/饮食指导服务，提升青训管理和教学质量。

### 1.3 术语定义

| 术语 | 说明 |
|------|------|
| JWT | JSON Web Token，用于身份认证的令牌 |
| SSE | Server-Sent Events，服务器推送技术 |
| BMI | 身体质量指数 |
| BCrypt | 密码加密算法 |
| RBAC | 基于角色的访问控制 |
| 会员等级 | 用户等级体系，分为 NORMAL/SILVER/GOLD/PLATINUM/DIAMOND |
| 积分 | 用户行为奖励，可用于抵扣课程预约费用 |
| 场上位置 | 球员在场上的职能位置，分为前锋/中场/后卫/门将 |
| 体能指标 | 反映球员身体与运动能力的量化数据（体脂率、冲刺、耐力等） |

## 2. 项目概述

智星足球青训综合管理系统是一个面向足球青训场景的综合性服务平台，采用前后端分离架构，提供会员端和管理端两个访问入口：

- **会员端（移动端适配）**：面向青训球员，提供体能管理、AI 训练/饮食咨询、课程预约、赛事活动参与等功能
- **管理端（PC 端）**：面向青训运营管理人员，提供球员管理、课程管理、评测管理、活动管理等管理功能

系统核心价值：
1. 帮助球员记录和管理自身体能训练数据
2. 通过 AI 结合球员身高、体型、体能数据提供个性化饮食与训练建议
3. 方便球员预约训练课程、报名赛事活动
4. 帮助青训管理人员提高教学与运营效率

## 4. 功能性需求

### 4.1 认证授权模块

#### 4.1.1 会员端需求
- 用户可通过手机号注册账号，注册需要短信验证码验证
- 用户可通过手机号和密码登录系统
- 支持双 Token 认证机制，Access Token 有效期 2 小时，Refresh Token 有效期 7 天，支持无感刷新
- 用户可主动注销登录，注销后 Token 失效
- 支持密码找回功能，通过短信验证码重置密码，重置后强制所有已登录设备下线
- 短信接口需要限流，防止恶意短信轰炸

#### 4.1.2 管理端需求
- 管理员通过同样的认证机制登录系统
- 基于角色的访问控制（RBAC）：PLAYER 角色只能访问会员端接口，ADMIN 角色可访问所有接口
- 管理员支持重置球员密码

### 4.2 体能记录模块

- 用户可录入日常体能/体检数据，包括身高、体重、体脂率、心率、肺活量、30 米冲刺、立定跳远、原地纵跳、12 分钟耐力跑等指标
- 系统根据用户身高体重自动计算 BMI 指数
- 用户可查询历史体能记录
- 系统可对用户体能数据进行趋势分析，计算最近 6 个月各项指标的平均值、最大值、最小值，生成趋势数据供前端展示图表
- 支持查看历史记录详情
- 当体能指标超出正常范围时，系统调用 AI 生成个性化训练/饮食建议，并作为站内消息内容推送给用户

### 4.3 技术/体能评测模块

- 用户可浏览已发布的技术/体能评测问卷
- 用户可填写问卷并提交
- 系统调用 AI 对用户答卷进行智能评分
- AI 根据答卷生成个性化训练/饮食建议
- 用户可查看自己的历史评测记录和建议

### 4.4 AI 对话模块

- 用户可创建新的 AI 对话会话
- 用户可向 AI 发送训练、战术、营养、恢复等相关问题
- 系统支持流式响应（SSE），实现打字机效果，提供更好的对话体验
- AI 携带最近 10 轮对话原文作为上下文，支持多轮对话；对话变长后系统自动将早期对话压缩为摘要随上下文携带，保持长期记忆
- 用户可查看对话历史
- 用户可删除不再需要的对话会话
- 系统提示词可在管理端配置

### 4.5 课程预约模块

- 用户可浏览所有可用的训练课程套餐，查看套餐详情（包含课程内容、教练、价格、适合水平）
- 用户可选择套餐，查看该套餐某日的可预约时段
- 用户可选择时段进行预约，预约需要扣除相应积分，积分不足时提示用户无法预约
- 系统需要处理并发预约场景，防止同一个时段被超额预约
- 用户可取消未完成的预约，取消后积分退还，发送短信通知
- 名额已满时提示用户无法预约
- 用户可查看自己的预约记录，查看预约状态
- 课程结束后，管理员可上传训练/表现报告，用户可查看下载报告 PDF
- 预约成功前 1 天发送提醒短信给用户

### 4.6 赛事活动模块

- 用户可浏览青训机构发布的赛事/训练营/选拔活动，查看活动详情（时间、地点、人数、内容）
- 用户可报名参加活动，报名需要控制并发，不超过活动人数上限，人数已满提示无法报名
- 活动开始后用户可签到，签到完成赠送 50 积分
- 用户可查看自己报名的活动列表

### 4.7 积分系统模块

- 新用户注册赠送 100 初始积分
- 活动签到赠送 50 积分
- 完成体能评测赠送 20 积分
- 课程预约需要扣除相应积分
- 积分变更使用数据库原子操作，防止并发问题

### 4.8 消息通知模块

- 系统支持发送站内消息给用户
- 系统支持短信通知（课程提醒、赛事提醒、体能提醒）
- 用户可查看消息列表，标记消息为已读，查看未读消息统计

### 4.9 个人中心模块

- 用户可查看和修改个人信息（真实姓名、性别、出生日期、身高、体重、场上位置、惯用脚、球龄、头像、紧急联系人电话）
- 用户可修改密码

### 4.10 管理端-仪表盘

- 显示系统数据概览统计，包括：球员总数、今日新增球员、今日课程预约数、今日赛事报名数、待完成预约数

### 4.11 管理端-球员管理

- 管理员可分页查询球员列表，支持按条件筛选（含场上位置筛选）
- 可查看球员详情（包含基本信息、位置、积分、体能记录、预约记录）
- 可启用/禁用球员账号，禁用后用户无法登录
- 可调整球员等级
- 可手动调整球员积分（增加/扣减）
- 支持重置球员密码

### 4.12 管理端-课程管理

- 管理员可对训练课程套餐进行增删改查
- 支持配置授课教练
- 支持批量生成课程预约时段
- 可管理用户预约，上传训练/表现报告

### 4.13 管理端-评测管理

- 管理员可创建和编辑技术/体能评测问卷
- 可管理问卷题目（单选/多选/文本类型）
- 可发布/下架问卷

### 4.14 管理端-赛事管理

- 管理员可创建编辑赛事/训练营/选拔活动
- 可设置活动报名时间、活动时间、人数上限
- 可查看活动报名列表，查看签到情况

### 4.15 管理端-消息管理

- 管理员可查看系统消息列表
- 可向单个或批量用户推送消息，支持短信+站内消息双通道

### 4.16 管理端-系统配置

- 管理员可管理系统配置参数
- 可修改 AI 对话系统提示词
- 可配置各项积分规则参数（注册赠送积分、签到赠送积分等）

## 5. 非功能性需求

### 5.1 性能需求

- 普通 API 接口响应时间 ≤ 200ms
- 复杂查询响应时间 ≤ 500ms
- AI 流式响应第一个字符返回时间 ≤ 1 秒
- 支持至少 1000 并发用户访问
- 数据库查询需合理设计索引，避免慢查询

### 5.2 安全性需求

- 用户密码使用 BCrypt 加密存储
- 采用 JWT 双 Token 认证机制，登出可立即失效 Token
- 使用参数化查询，防止 SQL 注入
- 前后端都要进行 XSS 防护
- 敏感体能数据采用 AES-256 加密存储
- 接口限流：登录接口限制 6 次/分钟，短信接口限制 3 次/分钟
- 同一手机号一天最多发送 10 条验证码
- 生产环境必须使用 HTTPS
- 所有业务表采用逻辑删除，数据可追溯
- 支持跨域配置，限定允许访问的域名

### 5.3 可用性需求

- 会员端界面适配移动端，针对青少年球员使用进行优化：
  - 界面简洁、操作步骤简化，避免多层级跳转
  - 按钮点击区域不小于 44px × 44px
  - 关键操作（如预约取消、密码修改）需要二次确认
- 系统全年可用率 ≥ 99.5%
- 故障恢复时间 ≤ 1 小时

### 5.4 可维护性需求

- 代码结构清晰，分层架构职责明确
- 提供统一异常处理和日志记录
- 关键业务流程需要有日志记录，便于问题排查；采用注解驱动的切面日志（登录、体能录入、评测提交、课程预约/取消等关键操作自动记录入参、耗时与成败，敏感字段脱敏）
- 数据库定期备份：每日全量备份保留 30 天，每 6 小时增量备份保留 7 天
- 过期数据定期归档：对话消息保留 6 个月，历史预约保留 2 年

### 5.5 兼容性需求

- 会员端支持移动端 Chrome、Safari 浏览器，要求兼容 iOS 14+ 和 Android 10+
- 管理端支持桌面端 Chrome、Edge、Firefox 浏览器最新 3 个版本
- 适配不同屏幕分辨率，移动端最小支持 360px 宽度

### 5.6 可扩展性需求

- 预留邀请好友、积分兑换礼品等功能扩展点
- 当前为单机部署，架构设计兼顾未来扩展需求，如需扩展可平滑升级为多机集群架构

## 9. 验收标准

### 9.1 功能验收

- 所有需求规格说明书中描述的功能都已实现
- 核心业务流程可正常走通：注册 → 登录 → 录入体能数据 → AI 咨询 → 课程预约 → 赛事报名

### 9.2 性能验收

- 普通接口响应时间满足性能需求
- 系统在预期并发压力下稳定运行

### 9.3 代码验收

- 代码可正常编译打包
- 没有严重代码安全漏洞
